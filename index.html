?どうやってセーブデータを持ってきたらいいの？

読み込むのは、ゲームのセーブデータのファイル main です。

① まず CFW(カスタムファームウェア)を入れる

3DS 本体の機能だけでは、セーブデータをファイルとして取り出すことはできません。取り出すには、3DS に CFW(カスタムファームウェア) を入れて、セーブデータを取り出すアプリ(Checkpoint)を使えるようにする必要があります。

CFW の入れ方は、こちらの動画をご参考ください。パソコン・iPhone・Android のどれか 1 台があればできます。

参考動画: CFW の導入方法YouTube で見る ↗

CFW の導入はご自身の責任で行ってください。

② Checkpoint でセーブデータを取り出す

  1. 3DS で Checkpoint を起動し、ポケモン X・Y / ORAS を選びます。
  2. 「Backup」(バックアップ)を押して、セーブデータを保存します。
  3. 3DS の電源を切って SD カードを抜き、パソコンやスマホで開きます。
  4. 3ds/Checkpoint/saves/ の中にあるゲーム名のフォルダを開き、保存した日時のフォルダの中の main を、このページで選びます。

JKSM を使っている場合も同じように「バックアップ」して、JKSM/Saves/ の中の main を選んでください。SD カードを抜かずに、ftpd などで Wi-Fi 経由でスマホやパソコンに移すこともできます。

エミュレータで遊んでいる場合、CFW は不要です。

  1. ゲームの一覧でポケモンを右クリック(スマホ版は長押し)します。
  2. 「セーブデータの場所を開く」を選びます。
  3. 開いたフォルダの中の main を、このページで選びます。

SD カードなどからセーブ全体を吸い出したファイル(.sav・.bin・.dat)も読み込めます。

「レポートがこわれています」と出たあとに新しく始めてレポートを書くと、壊れたデータが消えてしまいます。取り出すまでは、ゲームでレポートを書かないでください。

メニューの名前やフォルダの場所は、アプリやエミュレータの版によって違うことがあります。ゲームに戻すときは、必ず元のセーブのバックアップを取っておいてください。

破損データをサンプルとして管理者に提供しますか？

このツールについて

破損したポケモンのセーブデータをブラウザ内で解析し、内部に残っているポケモンや道具を取り出して、そのままゲームで遊べるセーブ(main)にします。壊れた部分が少なければ、セーブをまるごと復元することもできます。

対応予定・現在の対応

  • 第6世代：X / Y / オメガルビー / アルファサファイア（ゲームでそのまま開ける main）
  • 救出の出力：選んだポケモン（ボックス・手持ち・バトルボックス・育て屋）と、残っていたお金・バッグの道具・技マシン・薬・木の実をまとめて入れた main を出力します（お金と道具はバッグタブで入れるかどうかを切り替え。大切なものは対象外）。図鑑の登録状況とトレーナー名・ID も、読み取れれば入れます(それぞれのタブで選択)。
  • 正常なセーブだけでなく、セーブ全体のチェックサムが壊れている場合でも内部をスキャンします。
  • セーブデータの解析と救出したデータの作成は、すべてブラウザ内で行います。セーブデータが送信されるのは、「破損データのサンプル提供」で「はい」を選んだときと、「修復をリクエストする」で開いた修復依頼ページから送信したときだけです。なお、このページは広告（Google AdSense）と訪問者数などの集計（CountAPI）のために外部と通信します（セーブデータは含みません）。詳しくはプライバシーポリシーをご覧ください。

重要

これは「セーブを修復して元に戻す」ツールではなく、残存しているポケモン個体データを救出するためのツールです。検出結果には、チェックサムなどの内部構造がすべて一致した「完全な状態の個体」だけを表示します。復元に含める個体はユーザー自身がチェックボックスで選択できます。

検出されたデータは、内部構造・チェックサムなどを検証したうえで出力します。ゲームに戻す前に、必ず元のセーブのバックアップを取ってください。
