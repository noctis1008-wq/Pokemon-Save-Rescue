POKÉMON SAVE RECOVERY

破損したポケモンのセーブデータをブラウザ内で解析し、内部に残っている個体データを抽出し、PKHeXでボックス情報として読み込める boxdata.bin にまとめます。抽出したデータは、PKHeXで元のボックス位置を維持した1つの boxdata.bin として保存できます。

推定ソフト
救出したデータの使い方
  1. 「ポケモンを救出する」で main がダウンロードされます。選んだポケモン(ボックス・手持ち・バトルボックス・育て屋は元の場所)と、バッグタブで「お金を取り出す」「道具を取り出す」がオンのものが入っています。図鑑タブ・トレーナータブのチェックがオンなら、図鑑の登録状況とトレーナー名・ID も入ります。
  2. PKHeX でこの main を開くと確認できます。この main は救出用の空のセーブ(別のトレーナー)をもとにしているので、ポケモンは PKHeX などで自分のセーブへ移してください。
  3. 救出用の空のセーブがまだ用意されていないゲーム(現在はオメガルビー・アルファサファイア)では、代わりに boxdata.bin(ボックスのポケモンだけ)をダウンロードします。PKHeX で同じゲームのセーブを開いてから、boxdata.bin をウィンドウにドラッグ＆ドロップしてください。PC ボックス 31 個がまるごと置き換わるので、必ずバックアップを取ったセーブか、救出用の予備セーブで行ってください。

対応予定・現在の対応

  • 第6世代：X / Y / オメガルビー / アルファサファイア（PKHeX で開ける main。空のセーブがないゲームは boxdata.bin）
  • 救出の出力：選んだポケモン（ボックス・手持ち・バトルボックス・育て屋）と、残っていたお金・バッグの道具・技マシン・薬・木の実をまとめて入れた main を出力します（お金と道具はバッグタブで入れるかどうかを切り替え。大切なものは対象外）。図鑑の登録状況とトレーナー名・ID も、読み取れれば入れます(それぞれのタブで選択)。
  • 正常なセーブだけでなく、セーブ全体のチェックサムが壊れている場合でも内部をスキャンします。
  • 処理はすべてブラウザ内で行われ、セーブデータはサーバーへ送信されません。

重要

これは「セーブを修復して元に戻す」ツールではなく、残存しているポケモン個体データを救出するためのツールです。検出結果には、チェックサムなどの内部構造がすべて一致した「完全な状態の個体」だけを表示します。復元に含める個体はユーザー自身がチェックボックスで選択できます。

検出されたデータは、内部構造・チェックサムなどを検証したうえで出力します。最終的な利用可否はPKHeX等でも確認してください。
