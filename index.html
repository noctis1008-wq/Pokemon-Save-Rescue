このツールについて

破損したポケモンのセーブデータをブラウザ内で解析し、内部に残っているポケモンや道具を取り出して、そのままゲームで遊べるセーブ(main)にします。壊れた部分が少なければ、セーブをまるごと復元することもできます。

対応予定・現在の対応

  • 第6世代：X / Y / オメガルビー / アルファサファイア（ゲームでそのまま開ける main）
  • 救出の出力：選んだポケモン（ボックス・手持ち・バトルボックス・育て屋）と、残っていたお金・バッグの道具・技マシン・薬・木の実をまとめて入れた main を出力します（お金と道具はバッグタブで入れるかどうかを切り替え。大切なものは対象外）。図鑑の登録状況とトレーナー名・ID も、読み取れれば入れます(それぞれのタブで選択)。
  • 正常なセーブだけでなく、セーブ全体のチェックサムが壊れている場合でも内部をスキャンします。
  • セーブデータの解析と救出したデータの作成は、すべてブラウザ内で行います。セーブデータが送信されるのは、「破損データのサンプル提供」で「はい」を選んだときと、「修復をリクエストする」で開いた修復依頼ページから送信したときだけです。なお、このページは広告（Google AdSense）と訪問者数などの集計（CountAPI）のために外部と通信します（セーブデータは含みません）。詳しくはプライバシーポリシーをご覧ください。

重要

これは「セーブを修復して元に戻す」ツールではなく、残存しているポケモン個体データを救出するためのツールです。検出結果には、チェックサムなどの内部構造がすべて一致した「完全な状態の個体」だけを表示します。復元に含める個体はユーザー自身がチェックボックスで選択できます。

検出されたデータは、内部構造・チェックサムなどを検証したうえで出力します。ゲームに戻す前に、必ず元のセーブのバックアップを取ってください。
