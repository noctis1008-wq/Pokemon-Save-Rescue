このフォルダに、「ポケモンを救出する」で main を作るときに使う空のセーブを置きます。

  main_xy    … X または Y の main(Checkpoint で取り出したもの、ボックスが空) ← v23 で X を設置済み
  main_oras  … オメガルビー または アルファサファイア の main(同上) ← 2026-10-17 にアルファサファイアを設置済み

ファイル名は拡張子なしで、上の名前にしてください。
未設置のゲームでは、代わりに boxdata.bin(ボックスのポケモンだけ)を出力します。
置くセーブは、はじめから始めて最初のセーブをした程度の状態、
本名や普段使いではないトレーナー名、写真に個人が写っていないものにしてください
(サイトの利用者全員がこのセーブを受け取ることになるため)。
