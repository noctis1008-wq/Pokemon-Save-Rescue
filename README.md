# NER Pokémon Recovery

**バージョン: v76**(2026-10-21 / 変更履歴は `CHANGELOG.md`)

破損した第6世代ポケモンのセーブデータをブラウザ内で解析し、残存している
個体データ(PK6)を抽出して、PKHeX で読み込める `boxdata.bin` として
出力するツールです。解析と出力はすべてブラウザ内で行います。セーブデータが送信されるのは、利用者が「破損データのサンプル提供」で同意したときと、
修復依頼ページから送信したときだけです(広告の Google AdSense と、集計の CountAPI はセーブデータを含まない通信をします。詳しくは `privacy.html`)。

## 画面(v74〜)

1. **選ぶ**: 「ファイルを選ぶ」ボタン(パソコンではドラッグ&ドロップも可)。ふつうは拡張子なしの `main` を選びます。セーブデータの持ってき方は 3DS(CFW の導入から Checkpoint での取り出しまで)/ エミュレータ のタブで案内します。
2. **解析**: 「N匹のポケモンが見つかりました」と、セーブの状態(正常なブロックの数など)を表示します。くわしい診断は「くわしく」で開きます。
3. **選択**: 「救出」(選んだポケモンと道具を空のセーブに入れる)と「まるごと復元」(元のセーブを作り直す)を切り替えます。
   救出ではボックス表示(6×5 のマス。読み取れないマスは斜線・点線で区別)・一覧・手持ち/育て屋から選び、長押し・ⓘ ボタン・キーボードの i で詳細を開きます。
   まるごと復元では復元信頼度と失われている部分を表示し、ポケモンの選択はできません(セーブ全体を作り直すため)。
4. **書き出す**: スマホでは画面下、パソコン(幅 960px 以上)では右の欄の「セーブデータをダウンロード」。ダウンロードしたあとは結果の画面になり、「N匹のポケモンを救出しました」の枠の中に、次にすること・ゲームに戻す方法・もう一度ダウンロード・選択に戻るを表示します(v75〜、v76 で 1 つの枠に)。救出では、道具・お金・図鑑・アバター・ふしぎなおくりものを入れるかを同じ欄で切り替えられます。

読み込み時のアンケート(v73 まで)はなくし、切り替えスイッチに置き換えました。

## ファイル構成(v73〜)

ビルドは不要です(GitHub Pages にそのまま置けます)。v72 までの `app.js` は役割ごとに `js/` に分けました(以下の説明で `app.js` とあるものは `js/` のいずれか)。

| ファイル | 内容 |
| --- | --- |
| `js/version.js` | 版番号 `APP_VERSION`(`tools/set-version.js` が書き換える) |
| `js/core.js` | セーブのバイナリ処理: PK6 の暗号化・復号、ブロック表、チェックサム、位置合わせ、個体の走査(DOM を使わない) |
| `js/scan-worker.js` | 走査を画面を止めずに行う Web Worker(`core.js` を読み込む) |
| `js/parse.js` | 道具・お金・図鑑・ふしぎなおくりもの・トレーナー・手持ちなどの読み取り |
| `js/export.js` | 救出した `main`・`boxdata.bin`・まるごと復元の作成 |
| `js/ui.js` | 画面(一覧・タブ・ダイアログ・ダウンロード・サンプル提供・修復依頼) |
| `pkdata.js` ほか `pk_*.js` | 名前・アイコンなどのデータ |
| `counter.js` | 訪問者数・救出回数・いいね(CountAPI) |

`index.html` は データ → `version` → `core` → `parse` → `export` → `ui` → `counter` の順に読み込みます(通常のスクリプト。上から順に読み込む前提)。

## 版番号(v73〜)

版番号の元は `version.json` の 1 か所です。上げるときは `node tools/set-version.js 74` を実行すると、`version.json`・`js/version.js`・`index.html`/`privacy.html`/`style.css` の `?v=` がすべて同じ値になります。あとは `CHANGELOG.md` に見出しを足してください(そろっているかはテストで確認できます)。

## テスト(v73〜)

`node --test tests/` で実行します(node 18 以上、依存パッケージなし)。`templates/` と `test/` のセーブ(と、テスト中に作る回転・ずれ・破損・末尾欠けの変形)を解析し、結果が `tests/expected.json`(個数とハッシュのみ)と同じかを確かめます。解析・出力の結果を意図して変えたときは `node tests/update-expected.js` で作り直し、差分を確認してからコミットしてください。

## 対応

- 第6世代: X / Y(`0x65600`)、オメガルビー / アルファサファイア(`0x76000`)

ボックス位置はセーブ末尾のブロック表から判定し、セーブ全体がずれて保存されている場合も補正します。
第7世代は v19 で対象外にしました。

## 出力

- `boxdata.bin`: 31 ボックス × 30 匹 × 232 バイト = 215,760 バイト。
  再暗号化済みなので、PKHeX でセーブのボックス領域として読み込めます。
- `main`(「救出」で「セーブデータをダウンロード」。v73 までのボタン名は「ポケモンを救出する」): 運営者が用意した空のセーブ(`templates/main_xy`、`templates/main_oras`)に、
  選んだポケモン(ボックス・手持ち・バトルボックス・育て屋は元の場所へ)と、復元したお金・バッグの道具・技マシン・薬・木の実を
  書き込んだもの(お金と道具はバッグタブの「お金を取り出す」「道具を取り出す」で切り替え。図鑑とトレーナー情報も、それぞれのタブのチェックで入れるかを選べる)。大切なものは空のセーブのまま。PKHeX でこの `main` を開くだけで確認できます。
  空のセーブがないゲームでは、代わりに `boxdata.bin` を出力します。

## 空のセーブの設置

`templates/main_xy`(X または Y、**v23 で X を設置済み**)と `templates/main_oras`(オメガルビー または アルファサファイア、未設置)に、
Checkpoint で取り出したボックスが空の `main` をそのまま置きます(ファイル名は拡張子なし)。
未設置のゲームでは「救出」の「セーブデータをダウンロード」で `boxdata.bin` を出力します。

## 開発中の自動読み込み(v26〜。v59 から URL に ?dev を付けたときだけ)

`app.js` の `DEV_AUTOLOAD` に試験用セーブ(`test/main` = X、`test/main_oras` = AS)を指定しているため、ページを開くと X の試験用セーブを読み込んだ状態で表示され、開発用の帯で ORAS に切り替えられます。
`?noautoload` を付けると自動読み込みしません。**完成品として公開するときは `DEV_AUTOLOAD` を `null` にし、`test/` フォルダを削除してください。**

## 破損データのサンプル提供(v36〜)

結果の下の「破損データのサンプル提供にご協力ください。」の「提供する」→ 確認で「はい」のときだけ、読み込んだセーブを運営者の Google ドライブへ送ります。
送り先は `js/ui.js` の `SAMPLE_UPLOAD_URL`(Google Apps Script のウェブアプリ)。受け取り側のプログラムは `sample_receiver.gs`。

## セーブデータのまるごと復元(v38〜)

「まるごと復元」に切り替えて「セーブデータをダウンロード」を押すと、無事だったブロックを本来の位置に戻したセーブ(main)を作ります。失われたブロックは空のセーブで補います。
復元信頼度は、どれだけの部分を元に戻せるかの目安です。ゲームに戻す前に、必ず元のセーブのバックアップを取ってください。

## ポケモンのアイコン(v42〜)

ボックスのアイコンは [PokeSprite](https://msikma.github.io/pokesprite/) の画像(`img/pokemon/`)。画像は © Nintendo/Creatures Inc./GAME FREAK Inc.、PokeSprite のコードとデータは MIT ライセンス。種族番号・フォルム → ファイル名の対応は `pk_icons.js`。

## セキュアバリュー(v42〜)

第6世代のセーブはフッター先頭 16 バイトに「最後に保存した日時(セキュアバリュー)」と「その前の日時」を持つ。ダウンロード版では本体側にも同じ値が記録され、食い違うと読み込めないことがある。
- まるごと復元: 読み込んだセーブの値をそのまま使う。
- 救出: v42 から読み込んだセーブの値を書き込む(以前は空のセーブの値)。
