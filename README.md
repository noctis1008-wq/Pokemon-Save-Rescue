# NER Pokémon Recovery

**バージョン: v17**(2026-10-13 / 変更履歴は `CHANGELOG.md`)

破損した第6/7世代ポケモンのセーブデータをブラウザ内で解析し、残存している
個体データ(PK6 / PK7)を抽出して、PKHeX で読み込める `boxdata.bin` として
出力するツールです。処理はすべてブラウザ内で完結し、セーブデータは送信されません。

## 対応

- 第6世代: X / Y(`0x65600`)、オメガルビー / アルファサファイア(`0x76000`)
- 第7世代: サン / ムーン(`0x6BE00`)、ウルトラサン / ウルトラムーン(`0x6CC00`)

ボックス位置は第6世代では正確に再現されます。第7世代は PC ボックスの絶対位置が
セーブのブロック表で決まるため**推定**になります(UI に注意書きを表示します)。

## 出力

- 第6世代: 31 ボックス × 30 匹 × 232 バイト = 215,760 バイト
- 第7世代: 32 ボックス × 30 匹 × 232 バイト = 222,720 バイト

再暗号化済みなので、PKHeX でセーブのボックス領域として読み込めます。
