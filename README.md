# NER Pokémon Recovery

**バージョン: v20**(2026-10-15 / 変更履歴は `CHANGELOG.md`)

破損した第6世代ポケモンのセーブデータをブラウザ内で解析し、残存している
個体データ(PK6)を抽出して、PKHeX で読み込める `boxdata.bin` として
出力するツールです。処理はすべてブラウザ内で完結し、セーブデータは送信されません。

## 対応

- 第6世代: X / Y(`0x65600`)、オメガルビー / アルファサファイア(`0x76000`)

ボックス位置はセーブ末尾のブロック表から判定し、セーブ全体がずれて保存されている場合も補正します。
第7世代は v19 で対象外にしました。

## 出力

- `boxdata.bin`: 31 ボックス × 30 匹 × 232 バイト = 215,760 バイト。
  再暗号化済みなので、PKHeX でセーブのボックス領域として読み込めます。
- `main`(「道具を取り出す」): 運営者が用意した空のセーブ(`templates/main_xy`、`templates/main_oras`)に、
  復元したバッグの道具・技マシン・薬・木の実を書き込んだもの。大切なものは空のセーブのまま。
  PKHeX でこの `main` を開いてから `boxdata.bin` を読み込むと、ポケモンと道具がそろいます。

## 空のセーブの設置

`templates/main_xy`(X または Y)と `templates/main_oras`(オメガルビー または アルファサファイア)に、
Checkpoint で取り出したボックスが空の `main` をそのまま置きます(ファイル名は拡張子なし)。
未設置のゲームでは「道具を取り出す」を押すと、未設置である旨を表示します。
